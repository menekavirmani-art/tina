## Before running these

- **#1 overclaims**: "Every AI model". The studio covers about 15 models. Replace with e.g. "Veo, Kling, Sora. One studio."
- **"Free"**: the app is free and MIT licensed, but generations cost Kie.ai credits. #3 says "Bring your own API key"; #4's "Try it free" does not, so consider "Try it now".
- Check each ad platform's AI-generated content disclosure rules.
